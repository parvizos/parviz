# ParvizOS

Личная операционная система для жизни — **для одного пользователя, для тебя**.
Дела, проекты, задачи, сферы жизни, а дальше — финансы, люди, организации,
учёба и ежедневник. Всё в одном месте и, главное, **связано между собой**, а не
разбросано по восьми отдельным приложениям.

> Сделано намеренно без «нейрослопа»: настоящая связная модель данных, живые
> экраны без заглушек, быстрый интерфейс с клавиатуры, твои данные в одном файле.

---

## Что уже работает

**Дела** — полноценный менеджер задач:

- **Сегодня** — план на день + всё просроченное, быстрый ввод.
- **Входящие** — быстро скинуть мысль из головы, разобрать потом.
- **Предстоящее** — задачи с датами, разложенные по дням.
- **Проекты** — многошаговые дела с прогрессом и дедлайном.
- **Сферы** — зоны жизни (Учёба, Здоровье, Личное…), в которые складываются
  проекты и задачи.

Плюс: приоритеты, даты, заметки к задачам, вход по паролю, тёмная тема,
командная палитра `⌘K`, установка на телефон как приложение (PWA).

**Учёба** — студенческая жизнь:

- **Расписание** — недельная сетка пар по дням, с типом занятия и аудиторией.
- **Предметы** — дисциплины с преподавателем; на странице предмета собраны
  его расписание, домашка и конспекты.
- **Конспекты** — блокнот заметок, привязанных к предметам.
- **Домашка** — это обычная задача, привязанная к предмету: она сама попадает
  в «Сегодня» и «Предстоящее», а на «Сегодня» видно пары на текущий день.

**Ежедневник** — день как центр всего:

- Настроение и свободная запись за день (сохраняется автоматически).
- В одном дне сходятся **пары** (из расписания) и **план дня** — задачи и
  домашка, запланированные на эту дату.
- Переход по дням, быстрый прыжок к дате, лента недавних записей.

**Финансы** — учёт денег, связанный с остальным:

- **Счета** (карта, наличные, накопления) с балансом, который считается сам.
- **Операции** — доходы, расходы и переводы между счетами, по месяцам.
- **Категории** с месячными бюджетами и прогрессом по ним.
- **Обзор** — общий баланс, доход/расход за месяц, траты по категориям.
- Траты можно привязать к **сфере, предмету или проекту** — и видеть,
  сколько ушло на учёбу или конкретное дело.

**Люди и Организации** — личный CRM, который замыкает граф:

- **Люди** — контакты с ролью, организацией, днём рождения и заметкой;
  на странице человека собраны связанные с ним задачи и операции.
- **Организации** — вузы, компании и всё, к чему относятся люди.
- Человека можно привязать к **задаче** («встретиться с научруком») и к
  **трате** («репетитор», «кофе с Аней») — и всё это видно в одном месте.

Все домены из плана готовы. Как устроены связи между ними —
в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Быстрый старт (локально)

```bash
# 1. Зависимости
npm install

# 2. Настройки: скопируй пример и поменяй пароль и секрет
cp .env.example .env.local
#   APP_PASSWORD=свой-пароль
#   AUTH_SECRET=$(openssl rand -hex 32)
#   APP_TIMEZONE=Europe/Moscow   # свой часовой пояс

# 3. Запуск
npm run dev
# открой http://localhost:3000

# 4. (по желанию) демо-данные, чтобы увидеть систему живой
npm run db:seed
```

База создастся сама при первом запуске — миграции применяются автоматически.
Файл базы: `data/parviz.db`.

## Синхронизация телефон ↔ компьютер

Синхронизация здесь — это **один сервер как единая точка правды**: и телефон, и
ноут работают с одной базой. Никаких конфликтов и «какая версия свежее».

1. Разверни ParvizOS на маленьком сервере (VPS, домашний мини-ПК, Raspberry Pi)
   — проще всего через Docker (ниже).
2. Открой адрес сервера в браузере телефона → «Поделиться» → **«На экран
   Домой»**. Появится иконка как у обычного приложения (PWA, работает
   в полноэкранном режиме).
3. Заходи с любого устройства под своим паролем — данные одни и те же.

> Держи сервер за HTTPS (например, через Caddy или Nginx с Let's Encrypt) —
> тогда куки сессии идут только по шифрованному соединению.

## Самохостинг

### Docker (рекомендуется)

```bash
# положи рядом .env со своими APP_PASSWORD / AUTH_SECRET / APP_TIMEZONE
docker compose up -d --build
# http://localhost:3000  (данные — в ./data на хосте)
```

### Без Docker

```bash
npm install
npm run build
APP_PASSWORD=... AUTH_SECRET=... npm start
```

## Бэкапы

Все твои данные — в одном файле `data/parviz.db`. Бэкап = копия этого файла:

```bash
cp data/parviz.db "backups/parviz-$(date +%F).db"
```

Можно положить папку `data/` в облако/на автобэкап — этого достаточно.

## Переменные окружения

| Переменная            | Зачем                                             | По умолчанию            |
| --------------------- | ------------------------------------------------- | ----------------------- |
| `APP_PASSWORD`        | Пароль для входа                                  | `parviz` (обязательно поменять) |
| `AUTH_SECRET`         | Секрет для подписи сессии (`openssl rand -hex 32`)| небезопасный дефолт     |
| `DATABASE_URL`        | Где база. Локальный файл или удалённый libSQL      | `file:./data/parviz.db` |
| `DATABASE_AUTH_TOKEN` | Токен для удалённого libSQL/Turso (если нужен)     | —                       |
| `APP_TIMEZONE`        | Часовой пояс для расчёта «сегодня»                 | `Europe/Moscow`         |

## Стек

- **Next.js 16** (App Router, React 19, TypeScript) — один деплой: и сервер, и интерфейс.
- **SQLite через libSQL + Drizzle ORM** — реляционная база, один файл, твои данные.
- **Tailwind CSS 4** + собственные компоненты — единая дизайн-система, свет/тьма.

## Структура

```
src/
  app/               маршруты (Дела, проекты, сферы, вход)
  components/ui/      базовые компоненты (кнопки, поля, модалки)
  components/app/     логика приложения (меню, диалоги, палитра, задачи)
  db/                схема, клиент, миграции, seed
  lib/               запросы, серверные экшены, даты, аутентификация
drizzle/             SQL-миграции
```

## Горячие клавиши

- `⌘K` / `Ctrl+K` — командная палитра (поиск и действия)
- `N` — новая задача
